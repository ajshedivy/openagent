<task type="auto">
  <name>Task 1: Create publish-openagent.yml workflow</name>
  <files>.github/workflows/publish-openagent.yml</files>
  <action>
Create a new workflow file `.github/workflows/publish-openagent.yml` with the following content:

```yaml
name: publish-openagent

on:
  push:
    tags:
      - "v*"

permissions:
  contents: read

jobs:
  publish:
    runs-on: ubuntu-latest
    steps:
      - name: Checkout
        uses: actions/checkout@v4

      - name: Setup Bun
        uses: ./.github/actions/setup-bun

      - name: Typecheck
        run: bun turbo typecheck

      - name: Build
        run: bun turbo build

      - name: Setup Node for npm publish
        uses: actions/setup-node@v4
        with:
          node-version: "22"
          registry-url: "https://registry.npmjs.org"

      - name: Publish to npm
        working-directory: packages/opencode
        run: npm publish --access public
        env:
          NODE_AUTH_TOKEN: ${{ secrets.NPM_TOKEN }}
```

Key design decisions:
- **Trigger**: Only `v*` tags (e.g., `v0.1.0`). No branch filter needed since tags are explicit.
- **Runner**: `ubuntu-latest` (not the custom blacksmith runner from old workflow — keep it simple and portable).
- **Setup Bun**: Uses the existing `.github/actions/setup-bun` composite action which handles version pinning and caching.
- **Typecheck + Build**: Run via turbo to ensure the package compiles before publishing.
- **Node setup**: Required for `npm publish` since Bun doesn't natively support npm registry auth. Uses `actions/setup-node` which auto-configures `.npmrc` from `NODE_AUTH_TOKEN`.
- **npm publish**: Runs from `packages/opencode` directory with `--access public` (required for scoped packages on first publish).
- **NPM_TOKEN**: Must be added as a repository secret. This is a standard npm automation token.
- **No Docker, Tauri, AUR, or platform matrix** — this is a pure npm package publish.

Create a new workflow file `.github/workflows/ci.yml` with the following content:

```yaml
name: ci

on:
  pull_request:
    branches: [main]

jobs:
  check:
    runs-on: ubuntu-latest
    steps:
      - name: Checkout
        uses: actions/checkout@v4

      - name: Setup Bun
        uses: ./.github/actions/setup-bun

      - name: Typecheck
        run: bun turbo typecheck

      - name: Build
        run: bun turbo build
```

Key design decisions:
- **Trigger**: PRs targeting `main` only. This replaces the old `typecheck.yml` (which targeted `dev` branch).
- **Runner**: `ubuntu-latest` for simplicity.
- **Single job**: No matrix builds. Just typecheck + build as a quality gate.
- **No test step**: Tests require complex e2e setup (Playwright, opencode server, etc.) per the existing `test.yml`. Keep CI fast; tests can be added later as a separate workflow if needed.
- **No secrets required**: This workflow only validates code compiles.

<task type="auto">
  <name>Task 3: Remove private flag from package.json</name>
  <files>packages/opencode/package.json</files>
  <action>
The package.json currently has `"private": true` on line 18. This **blocks** `npm publish` — npm refuses to publish private packages.

Remove the `"private": true` line from `packages/opencode/package.json`.

Also add a `"files"` field to control what gets published to npm. Without it, npm publishes everything except what's in `.gitignore`. Add a restrictive files list to keep the published package clean:

```json
"files": [
  "bin/",
  "dist/",
  "src/",
  "package.json",
  "README.md",
  "LICENSE"
]
```

Place the `"files"` field after the `"license"` field (line 17) and before the `"scripts"` field.

Do NOT change any other fields in package.json.

**Why `src/` is included**: The package uses `"exports": { "./*": "./src/*.ts" }` so consumers importing from the package need source files. The `bin/openagent` entry point also needs the `bin/` directory. `dist/` is included for the compiled build output.
  </action>
