<task type="auto">
  <name>Task 1: Create install.sh build-from-source script</name>
  <files>install.sh</files>
  <action>
Create `install.sh` at the repo root (alongside the existing `install` file which is the upstream opencode remote-download installer). This is a NEW file, not a modification of the existing `install` script.

The script must:

1. **Shebang and strict mode**: `#!/usr/bin/env bash` with `set -euo pipefail`

2. **Dependency checks**:
   - Check `bun` is installed (`command -v bun`). If not: print clear error message explaining Bun is required, link to https://bun.sh, and exit 1.
   - Check `git` is installed (needed for version detection in build script). If not: print clear error.

3. **Detect repo root**: Use `cd "$(dirname "$0")"` to ensure script runs from repo root regardless of where it's invoked from.

4. **Install dependencies**: Run `bun install` in the repo root. This installs the monorepo dependencies including the opencode package.

5. **Build for current platform**: Run `cd packages/opencode && bun run build --single` which uses the existing `build.ts` script with `--single` flag to build only for the current OS/arch combination. The build script uses `bun build --compile` under the hood to produce a standalone binary.

6. **Locate the built binary**: After build, the binary is at `packages/opencode/dist/@worksofadam/openagent-{os}-{arch}/bin/openagent` (the build script uses the package name as prefix). Detect OS and arch the same way build.ts does:
   - `os`: `darwin`, `linux`, or `windows` (map from `uname -s`)
   - `arch`: `arm64` or `x64` (map from `uname -m`, handle `aarch64` -> `arm64`, `x86_64` -> `x64`)
   - Binary path pattern: `packages/opencode/dist/@worksofadam/openagent-${os}-${arch}/bin/openagent`

7. **Install the binary**:
   - Create `~/.openagent/bin/` directory
   - Copy the built binary to `~/.openagent/bin/openagent`
   - `chmod +x ~/.openagent/bin/openagent`

8. **PATH setup**: Add `~/.openagent/bin` to PATH in shell config (same approach as existing `install` script):
   - Support `--no-modify-path` flag to skip
   - Detect shell (zsh, bash, fish, etc.)
   - Add `export PATH=$HOME/.openagent/bin:$PATH` to appropriate config file
   - Skip if already present

9. **Success message**: Print:
   ```
   openagent installed successfully!

   Binary: ~/.openagent/bin/openagent
   Version: [output of openagent --version]

   Restart your shell or run:
     export PATH=$HOME/.openagent/bin:$PATH

   Then run:
     cd <project>
     openagent
   ```

10. **Command-line flags**:
    - `-h, --help`: Show usage
    - `--no-modify-path`: Skip shell config modification

Style notes:
- Use same color scheme as existing `install` script (MUTED, RED, ORANGE, NC)
- Keep it simple — no download logic, no version checking against remote, no archive extraction. This is a BUILD FROM SOURCE script.
- Error messages should be actionable (tell user what to do to fix)
  </action>
