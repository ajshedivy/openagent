<task type="auto">
  <name>Task 1: Squash history into single initial commit</name>
  <files>.git/</files>
  <action>
Create an orphan branch to establish a clean history root, then commit all files as a single initial commit with proper opencode attribution.

Steps:
1. Verify clean working directory with `git status`
2. Create orphan branch: `git checkout --orphan new-main`
3. Verify all files are staged with `git status`
4. Create initial commit with attribution message using heredoc:

```bash
git commit -m "$(cat <<'EOF'
Initial commit: OpenAgent fork from OpenCode

This repository represents a clean divergence point from the OpenCode project.
All previous development history (8,464 commits) has been squashed into this
initial commit to establish repository independence.

Original project: https://github.com/sst/opencode
Original authors: SST and OpenCode contributors
Fork date: 2026-01-31
License: MIT (preserved from original project)

Co-authored-by: OpenCode Contributors <noreply@github.com>
EOF
)"
```

5. Delete the old branch: `git branch -D opencode-agno`
6. Rename orphan branch to main: `git branch -m main`

IMPORTANT: Do NOT use git add -A or git add . - the orphan branch automatically stages files from previous HEAD. Just commit directly after creating the orphan branch.
  </action>
  <verify>
Run `git log --oneline` - should show exactly ONE commit.
Run `git log -1 --format=%B | grep "Co-authored-by"` - should show the attribution trailer.
  </verify>
  <done>
Main branch has exactly one commit with proper attribution message containing "OpenAgent fork from OpenCode" and "Co-authored-by: OpenCode Contributors" trailer.
  </done>
</task>

<task type="auto">
  <name>Task 2: Reconfigure remote and push to new repository</name>
  <files>.git/config</files>
  <action>
Update the origin remote to point to the new openagent repository and push the squashed history.

Steps:
1. Verify current remotes: `git remote -v`
2. Change origin URL: `git remote set-url origin https://github.com/ajshedivy/openagent.git`
3. Remove upstream remote (no longer tracking original): `git remote remove upstream`
4. Verify remote change: `git remote -v` - should show only origin pointing to openagent
5. Push to new repository with upstream tracking: `git push -u origin main`

NOTE: First push to an empty repository does NOT need --force. If the repository already has commits, you may need `git push -u origin main --force` but check with user first if that's needed.

If authentication is required, this will trigger an auth gate - let the executor handle the authentication flow.
