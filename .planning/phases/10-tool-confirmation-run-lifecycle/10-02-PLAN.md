**Part A: Wire abort signal to cancelRun in doStream()**

In `doStream()`, add an abort signal listener that calls `cancelRun()` when the stream is aborted. The `runId` is captured from the `RunStarted` event. Add the listener after receiving `RunStarted`:

Inside the `case "RunStarted"` handler, after setting `runId`, add:
```typescript
// Wire abort signal to cancel run
if (options.abortSignal && runId) {
  const onAbort = () => {
    self.cancelRun(runId!).catch((err) => {
      debugLog("Failed to cancel run", err)
    })
  }
  if (options.abortSignal.aborted) {
    onAbort()
  } else {
    options.abortSignal.addEventListener("abort", onAbort, { once: true })
  }
}
```
