# Milestone v1.0: Minimal Divergence

**Status:** ✅ SHIPPED 2026-01-31
**Phases:** 1-2
**Total Plans:** 3

## Overview

This minimal divergence milestone establishes openagent as an independent project forked from opencode. Phase 1 creates a clean git history with squashed commits and pushes to the new repository. Phase 2 renames the CLI binary, updates branding, and documents the initiative. All 8 requirements deliver the minimum viable divergence while preserving existing AgentOS integration.

## Milestone Summary

**Key Decisions:**

- Fork opencode rather than build from scratch — Leverage mature TUI infrastructure
- Rename to "openagent" — Clear identity as AgentOS client, distinct from opencode
- Focus on AgentOS API exclusively — Simplify architecture, align with AgentOS ecosystem
- Squashed 8,464 commits into single initial commit — Establish clean divergence point
- Preserved MIT license and opencode attribution via Co-authored-by trailer

**Issues Resolved:**

- Clean separation from original opencode project achieved
- Attribution requirements satisfied via commit message and trailer

**Issues Deferred:**

- Full package scope rename (@opencode-ai/* → @openagent/*) — v2.0
- Directory restructure (packages/opencode/ → packages/openagent/) — v2.0
- Environment variable rename (OPENCODE_* → OPENAGENT_*) — v2.0
- Platform binary package creation (openagent-{platform}-{arch}) — distribution milestone

**Technical Debt Incurred:**

- 14 files in build infrastructure still reference bin/opencode
- Old branches (dev, agno, exciting-snyder) retain 8,464-commit history
- Platform binary packages not yet created (required for npm distribution)
